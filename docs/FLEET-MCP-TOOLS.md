# Fleet MCP tools

The separate fleet stdio server is created by `src/mcp/fleet-server.ts`. This catalog describes its `tools/list` registrations, distinct from the native gateway in [MCP-TOOLS.md](https://github.com/ashlrai/phantom/blob/master/docs/MCP-TOOLS.md). Listing tools proves only the advertised contract; it does not verify an installed or live runtime, execution, assignment, ownership, or delivery. Descriptions are JSON string content (without surrounding quotes), with Markdown pipes escaped as `\|`; decode those escapes before parsing the JSON string. Individual descriptions state their evidence and authority boundaries.

| `fleet_staging_inventory` | Inventory the local release-staging directory: children (name, modifiedAt, bytes), total measured bytes, completeness flags, skipped symlink count, and an age-and-size disclaimer. The tool *only* reports measured size; measurement does not grant permission to clean, reclaim, or unblock any launch. Root is the fixed ~/.local/share/ashlr/release-staging path — no arbitrary root or command parameter is accepted. |
