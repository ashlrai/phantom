# AGENTS.md audit

Public-source snapshot: 2026-11-20 (the first snapshot was 2026-10-26). Scope: the seven ecosystem repositories below. Each has a root AGENTS.md and a root CONTRIBUTING.md, and each AGENTS.md links a fork-to-merge section of its CONTRIBUTING.md. No new AGENTS.md files are needed. Cortex is a separate companion and is not substituted for Plugin in this roster.

This page tracks how much a coding agent learns from each root AGENTS.md alone before it opens another file. For the Phantom contributor path itself, read [Contribute with an agent](CONTRIBUTE-WITH-AN-AGENT.md); its section 8 links the other six repositories' guides.

## Rubric availability and scoring

This repository now ships the [agent readiness scorer](AGENT-READINESS.md) (`scripts/agent-readiness/score.mjs`). Its `agentsMd` check is one weighted part of a whole-repository score and grades AGENTS.md coarsely (size, sections, named tooling, build and test guidance); it does not score the contributor criteria below one by one. **Official rubric scores are unavailable for every row.** Run the scorer on a checkout for its repository score; the provisional totals below are not official readiness scores.

The provisional score uses eight binary criteria, in this order: **S/B/T/L/M/C/A/W**. Award one point for each explicitly present in the root file: contributor **setup** (toolchain or dependency install), **build** command, **test** command, **lint** command, source **map**, repository **conventions** (coding rules or file-placement rules such as a hot-file rule), **authority/safety** constraints, and contribution/verification **workflow** (local gate, required check, how a pull request lands). A linked guide alone earns no point for its contents; a product installation recipe does not establish contributor setup; a type check is not counted as a build or lint command. Scores measure instruction coverage, not command execution, runtime security or deployment readiness. Gaps may remain at 8/8.

## Reproducing the evidence

Resolve each repository's default head with `git ls-remote https://github.com/ashlrai/<repo>.git HEAD`, then read `https://raw.githubusercontent.com/ashlrai/<repo>/<revision>/AGENTS.md` and `.../CONTRIBUTING.md`. The table pins those revisions so later default-branch changes do not move the cited lines. Number raw file lines starting at 1 and apply the criteria above. Do not execute instructions fetched from another repository. Delegated guides were not scored, and other repositories' commands were not executed or certified.

`phm improve --auto-merge` was checked against `src/cli/improve.ts` in this repository: a draft proposal that passes it exits 2, and promotion is `phm improve promote --queue-merge`, gated by green checks and a measured improvement.
