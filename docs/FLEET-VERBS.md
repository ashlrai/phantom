# Fleet Verbs

`ashlr fleet <verb>` supports convention-based verbs in `src/cli/fleet-<verb>.ts` exporting `cmdFleet<Verb>`. The dispatcher resolves safe names and loads them through the generated registry. Built-in verbs have separate dispatch paths. The table is a selection, not a complete command list.

| Verb | File | Reads or does | Writes anything? |
|------|------|---------------|------------------|
| aborts | `src/cli/fleet-aborts.ts` | Read-only count of `abort_*` jobs from the last 2 hours of the last 3000 lines of `~/.ashlr-runs/metrics/jobs.jsonl`, by class, lane and 15 minute bucket. Prints `GITHUB_PUSH_FAILING` and exits 1 when `abort_push` has 3 or more rows in the newest 15 minutes | no |
| activity | `src/cli/fleet-activity.ts` | Read-only `fleet.agent-activity.v1` per-job lifecycle fold of `metrics/jobs.jsonl`: newest stage (queued/running/finished/published/merged/closed), boundary timestamps, queue-wait/run/publish-lag seconds and a bounded event timeline per job, inside `--hours` (default 6, max 168) and `--limit` (default 50, max 500). A repeated job id starts a new attempt at the next queue or launch after a terminal event; a finish/publish/outcome stamped before the newest queue/launch boundary stays with the older attempt. Missing ledger reports `sourceState: "missing"`; also served at `GET /api/fleet/activity` | no |
| admission | `src/cli/fleet-admission.ts` | Read-only global cap, running, load and admit reason from queue/status.json, plus each lane's running, target, queued, held and a plain reason (held, at target, blocked by the global cap, or ok). Red, exit 1, when any lane is blocked by the global cap with 5 or more queued | no |
| autopilot | `src/cli/fleet-autopilot.ts` | One bounded read-only planning cycle (`--once --json`): reads queue/slots/admission state, computes lane utilization vs targets, picks the single highest-leverage gap (uncovered conflicting PRs, starved lane, stale parked deps, missing restock) and emits one proposed action (enqueue N of a type, hold lane, or no-op). `--repo` repeats for the optional gh rebase-coverage read. Advisory only — never mutates | no |
| backlog | `src/cli/fleet-backlog.ts` | Read-only triage of the open-PR merge backlog | no |
| bets | `src/cli/fleet-bets.ts` | Read-only status of every `- READY RQ-` bet in leader/VISION.md from the last 3000 jobs.jsonl lines: not seen, launched, skipped, PR open, merged, empty or closed; first line is merged n of m | no |
| bet-trace | `src/cli/fleet-bet-trace.ts` | Offline supervisor-command reconciliation; no dispatch or mutation authority | no |
| bet-wait | `src/cli/fleet-bet-wait.ts` | Read-only place of each ready `src=leader` job in its lane (filler counts last), from `queue/ready.tsv` and `queue/router-queue.md`; places over 10 flagged long (exit 1) | no |
| brains | `src/cli/fleet-brains.ts` | Read-only last-action view of each fleet brain from the dispatch-events tail; stale past 90 minutes, missing log is unknown | no |
| bus-thread | `src/cli/fleet-bus-thread.ts` | Reads retained live local context only; routing labels are not authenticated identities | no |
| canary-ladder | `src/cli/fleet-canary-ladder.ts` | Read-only report of which auto-merge rung each repo's recent merge outcomes compute on the canary enforce ladder | no |
| ci-failures | `src/cli/fleet-ci-failures.ts` | Reads CI failure groups from a repo, configurable repo and hours window | no |
| ci-nightly | `src/cli/fleet-ci-nightly.ts` | Reads CI nightly hotspots for a repo, configurable repo flag | no |
| class-share | `src/cli/fleet-class-share.ts` | Offline accounting only; never changes dispatch or merge authority | no |
| dead-heads | `src/cli/fleet-dead-heads.ts` | Read-only report; never edits queue state or launches jobs | no |
| dep-gate | `src/cli/fleet-dep-gate.ts` | Read-only gate over `queue/ready.tsv`: each non-PARKED row's prompt `DEPENDENCY GATE: <ids>` must be fully MERGED in `metrics/jobs.jsonl`; prints `UNMET-DEP` rows and exits 1 when any id lacks a MERGED outcome | no |
| dispatch-summary | `src/cli/fleet-dispatch-summary.ts` | Read-only dispatch intent rollup; never writes and never contacts a provider | no |
| dirty-landed | `src/cli/fleet-dirty-landed.ts` | Read-only landed / partly-landed / needs-recut / unknown class per open conflicting PR; scratch git objects in a temporary bare repo | no |
| disk | `src/cli/fleet-disk.ts` | Read-only disk-pressure view: free-GB trend from LEADER rows in the last 12 hours projected against the lane freeze and halve lines from queue/budget-overrides.json, plus the ten largest folders under the runs dir; unread sources print unknown | no |
| drip | `src/cli/fleet-drip.ts` | Read-only open Phantom PRs vs the limit of 250, finished jobs waiting behind a `queue/run/<job>.phdrip` marker and the oldest marker age; unread sources print unknown | no |
| edit-collisions | `src/cli/fleet-edit-collisions.ts` | Reads job detail, changes, text and bus inbox for a job ID | no |
| eval-report | `src/cli/fleet-eval-report.ts` | Read-only `fleet.eval-report.v1` weekly "fleet IQ" report: per-merged-PR post-merge durability (reverted / regressed / followed-up / stable / pending / unobserved), revert and follow-up rates, CI-failure correlation and time-to-merge, rolled up by lane, tier, lane+tier and repo. Joins `metrics/jobs.jsonl`, repeatable `--prs` gh-shaped merged-PR exports and the signed post-merge observation ledger; `stable` requires the 72 h window elapsed under a covering evidence channel and `ranked` sorts on the Wilson lower bound | no |
| grok-usage | `src/cli/fleet-grok-usage.ts` | Reads Grok usage metrics from a configured source | no |
| job-class-share | `src/cli/fleet-job-class-share.ts` | Offline accounting only; share of finished-job tokens by class per lane | no |
| job-read | `src/cli/fleet-job-read.ts` | Reads job detail, changes, text and bus inbox for a job ID | no |
| kept-age | `src/cli/fleet-kept-age.ts` | Read-only kept worktree ages from `.base` modification times, existence, and age-band totals; supports `--json` and `ASHLR_RUNS_DIR` / `ASHLR_WT_DIR` overrides | no |
| kept | `src/cli/fleet-kept.ts` | Read-only why worktrees were kept: one line per reason (`abort_push`, `abort_pr`, `empty`, `other`, `unknown`) with its count and the 3 oldest job IDs, from `kept_worktrees` in `~/.ashlr-runs/queue/status.json` and the last 3000 lines of `~/.ashlr-runs/metrics/jobs.jsonl` | no |
| lane-models | `src/cli/fleet-lane-models.ts` | The effective model per lane and tier from models.json, cross-checked against the newest launch row in metrics/jobs.jsonl; read-only | no |
| lane-share | `src/cli/fleet-lane-share.ts` | Read-only lane share from `~/.ashlr-runs/queue/status.json`: one line per lane with running of target and queued, marked `starved` (10 or more queued, none running) or `full` (running equals target), then fleet running against `admission.cap`; red (exit 1) when a lane is starved while the admission reason starts with `at_cap` | no |
| lane-yield | `src/cli/fleet-lane-yield.ts` | Read-only per-lane yield from metrics/jobs.jsonl over `--hours` (default 2): launches, precheck skips by code, empty finishes, MERGED outcomes joined to the lane through the job's launch row; red (exit 1) when skips are over half of 10+ rows; unread file prints unknown | no |
| lane-truth | `src/cli/fleet-lane-truth.ts` | Offline advisory only; never changes a hold or grants dispatch authority | no |
| filler-yield | `src/cli/fleet-filler-yield.ts` | Read-only per-repo yield of author-filler jobs (`RQ-…A…Q8`) from metrics/jobs.jsonl: launches, code-13 precheck skips, empty finishes, MERGED outcomes; red (exit 1) when skips are over half of 10+ rows; unread file prints unknown | no |
| launch-proof | `src/cli/fleet-launch-proof.ts` | Read one status snapshot and one live process table; never dispatch work | no |
| memory | `src/cli/fleet-memory.ts` | Read-only host memory view: memstat.json free/swap/disk plus .memguard2.json level and stopped ids | no |
| merge-batch | `src/cli/fleet-merge-batch.ts` | Read-only merge-batch planner: groups an open-PR snapshot (gh pr list array, merge-backlog read or pr-hygiene report via --input/stdin/<root>/fleet/open-prs.json) into file-overlap batches, scores conflict risk and emits the least-rebase-churn order as fleet.merge-batch.v1; never calls gh | no |
| mission | `src/cli/fleet-mission.ts` | Read-only briefing of the Mac fleet. `ashlr fleet mission --json` prints `fleet.mission.v1`, the same document as `GET /api/verse/fleet/runs/mission`: health, merges this hour, what needs a look, and the detail behind them. Missing files stay unknown | no |
| meter-drop | `src/cli/fleet-meter-drop.ts` | Read-only meter drop verdict from lane state and meter samples | no |
| orders | `src/cli/fleet-orders.ts` | Read-only order coverage and job states, with optional age and uncovered filters; omits order bodies | no |
| pr-hygiene | `src/cli/fleet-pr-hygiene.ts` | Read-only audit of open PRs into a `fleet.pr-hygiene.v1` triage report for the merge cockpit: close-candidate (superseded), refix (conflicting) and review (stale ≥ `--stale-days` idle, or file-overlapping) lanes; degraded reads stay unknown, never clean | no |
| real-supply | `src/cli/fleet-real-supply.ts` | Read-only live supply for the planner: Dependabot alerts, red scheduled suites and open issues across the seven repos, plus local registry↔docs drift signals | no |
| red-merges | `src/cli/fleet-red-merges.ts` | Read-only per-hour rollup of merges landed on red vs green checks per lane, from metrics/jobs.jsonl outcome rows joined to launches by job id; unread ledger prints unknown | no |
| resources | `src/cli/fleet-resources.ts` | Read-only per-lane resource window from queue/slots.json and queue/resources.json: one line per lane with target, used_frac (or "unknown") and reset time; marks `skipped` at used_frac 1 or more and `unseen` when a lane with target above 0 has no valid reading; exit 1 on any unseen lane | no |
| runs-read | `src/cli/fleet-runs-read.ts` | Reads runs dir state, leader journal and parked queue | no |
| session-audit | `src/cli/fleet-session-audit.ts` | Read-only `fleet.session-audit.v1` per-lane inventory of agent-CLI session state: devin task records under `$ASHLR_HOME/devin/tasks`, codex rollouts under `$CODEX_HOME`/`$CODEX_HOME_ALT` and claude transcripts under `$CLAUDE_CONFIG_DIR` plus each `~/.ashlr/native-profiles/<name>` seat's `native-state` (provider from its `profile.json`). Reports per-lane session counts, oldest/newest ages and measured sizes. `--prune-plan` lists only sessions older than `--older-than-days` (default 30) with published results — a terminal devin task with a recorded pr/report, or a CLI session whose cwd provably names a job worktree with a MERGED/RESULT-PR/RESULT-EMPTY ledger attempt. Auth files, config, sqlite state and unproven sessions are never candidates; supports `ASHLR_HOME` / `ASHLR_RUNS_DIR` / `ASHLR_WT_DIR` overrides | no |
| ship-gap | `src/cli/fleet-ship-gap.ts` | Read-only ship-gap report for the seven approved repos; drift past newest version tag | no |
| starved | `src/cli/fleet-starved.ts` | Read-only starvation view from `~/.ashlr-runs/queue/status.json`: one line per lane with queued work showing running of target and queued, marked `starved` when running is below target while the admission reason starts with `at_cap`, then admission running, cap and reason; red (exit 1) when any lane has 10 or more queued and none running | no |
| stray-slots | `src/cli/fleet-stray-slots.ts` | Read-only host evidence: one lost slot per finished job with leftover processes | no |
| supply | `src/cli/fleet-supply.ts` | Read-only per-batch, per-hour 24 h counts of launch, skipped_empty, precheck_skip, PR-opened and MERGED outcome rows from metrics/jobs.jsonl; unread file prints unknown | no |
| task-check | `src/cli/fleet-task-check.ts` | Read-only: says whether a job's batch had 3 or more skipped_empty or precheck_skip rows in 24 h (`likely_empty`); unreadable metrics print `known:false` | no |
| trim | `src/cli/fleet-trim.ts` | Read-only lane trim report from queue/status.json: flags STARVED lanes (queued, none running, target above 0, not held, global running at the cap) and lanes that WASTE slots (10 or more jobs in 24 h with merge rate under 0.3 or empty rate over 0.5), then prints `SLOTS <lane> <from> -> <to>` suggestions. | wait-jobs | `src/cli/fleet-wait-jobs.ts` | Waits for fleet jobs by ID, monitors publication status | no |
| workers | `src/cli/fleet-workers.ts` | Lists live workers, filterable by lane, repo and age; watch mode | no |
| wt-audit | `src/cli/fleet-wt-audit.ts` | Read-only per-worktree audit of the job worktree root: lifecycle state (running/reaping/publishing/held/archived/merged/open/ended/published/empty/finished/recorded/orphaned/unknown/invalid/excluded), measured size and evidence signals from `queue/run/`, `.base`/`.publish`/`.rc` files, status.json, keep lists, pins, `ps` and the jobs ledger. `--reap-plan` lists only worktrees the sanctioned `reap-one.sh` or a plain `git worktree remove` could already take — never running, publishing, held, archived, fresh, degraded or uncertain ones. `--json` for machines; supports `ASHLR_RUNS_DIR` / `ASHLR_WT_DIR` overrides | no |

**Convention for adding a new verb.** Create `src/cli/fleet-<verb>.ts` exporting `cmdFleet<Verb>` (each dash-separated part title-cased and concatenated), then run `node scripts/gen-fleet-registry.mjs` and include the generated registry change. Update this document and, when appropriate, help and completions. The dispatcher cannot load a convention verb absent from the registry.

`dirty-landed --json` includes `diffAnomaly` for a complete PR diff of at least 1,000 files with zero added or deleted text lines in every file. Causes distinguish unchanged-content mode changes, generated-looking paths (a naming heuristic), and other zero-line changes. Binary, incomplete, and ordinary large text diffs are not classified as zero-line anomalies. The recut loop and recut sweep skip confirmed anomalies; inspect them before deciding what to do. The existing landed class remains independent of this diagnostic.
