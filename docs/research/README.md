# Research

The `research/` folder stores offline studies, topic inventories, and daily
harness digests so agents can discover what has been researched without
scanning commit history.

- **[TOPICS.md](TOPICS.md)** — The offline restock source that reads bullet entries in the form `- STABLE-ID | question` for the daily research queue.
- **[agent-swarms-rsi.md](agent-swarms-rsi.md)** — Research and experiment specifications on agent swarms and recursive self-improvement, dated 2026-10-26.
- **[harness-digest-2026-10-31.md](harness-digest-2026-10-31.md)** — What the leading agent harnesses shipped in late October 2026, checked on 2026-10-31 UTC against public changelogs.
- **[speculative-parallel-memory.md](speculative-parallel-memory.md)** — Research on speculative execution, bounded parallelism and agent memory from the `a6f3c323` repository.
- **[AGENT-NETWORK-RESEARCH.md](AGENT-NETWORK-RESEARCH.md)**: Cross-vendor agent identity, native bus integration, Slack, Telegram, local iMessage, Gmail drafts, threat models and proposed interfaces. Handoff reconciliation remains blocked by host access permissions.
- **[RQ-OSS-SPEED-LOCAL-1.md](RQ-OSS-SPEED-LOCAL-1.md)** — Local inference, quantization, routing and agent efficiency research.
- **[RQ-OSS-DESKTOP-UX-1.md](RQ-OSS-DESKTOP-UX-1.md)**: License-verified survey of ~50 OSS desktop agent UIs (adopt/fork/inspire-only/skip), the OSS "Grok Bot–like" hunt, and desktop UX patterns for the Phantom workbench, dated 2026-11-06.
- **[RQ-OSS-A2A-ORCH-1.md](RQ-OSS-A2A-ORCH-1.md)**: Ranked OSS survey (26 projects, licenses verified per-row) of agent-to-agent protocols, durable orchestration runtimes and subagent pattern libraries; recommends A2A schema alignment and a Hatchet/DBOS spike for cross-host job handoff. Dated 2026-11-06.
- **[fleet-digest-2026-11-08.md](fleet-digest-2026-11-08.md)** — First input digest for the research loop (RQ-SWE5-RESEARCH-LOOP): Spawn fleet model, agent/eval/merge-queue sources, and a `## Proposals` section consumed by `phm fleet research-digest`. Dated 2026-11-08.
