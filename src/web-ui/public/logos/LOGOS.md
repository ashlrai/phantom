# Ashlr ecosystem logos

- [Ashlr.ai artwork](https://ashlr.ai/): Phantom, Phantom Secrets, Lexicon, Locus, Ashlr MD, AshlrCode, Binshield, Cortex and the AshlrAI wordmark. The site calls the Phantom P `phantom-workbench-logo.svg` and the Secrets ghost `phantom-logo.svg`; the latter is bundled as `phantom-secrets-logo.svg`.
- [Ashlr Plugin's mark on Ashlr.ai](https://ashlr.ai/logos/plugin-logo.svg), bundled as `ashlr-plugin-logo.svg`.
- [Ashlr Stack's site mark](https://github.com/ashlrai/ashlr-stack/blob/69172e49b5b9b5ef3cc54ce2a276d5edf220409f/packages/site/public/favicon.svg).

Use the ecosystem brand registry in `src/core/brand/ecosystem.ts` for named project lists. An unbranded entry keeps its text label. The repo-sourced marks use the AshlrAI [MIT notice](../phantom-mark.LICENSE.txt).
