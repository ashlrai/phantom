Install

Install Phantom.

Phantom is the open-source engineering agent workbench from AshlrAI, published as @ashlr/phantom on npm under the MIT license. The CLI runs on macOS, Linux and Windows; phm and ashlr are the same binary under two names.

What you need

  • Node.js 22.15 or newer and Git.
  • Whichever agent CLIs you already use; each signs in with the vendor's own login.
  • Optional: Ollama for local model discovery.
  • Optional: a Mac for the desktop app and resident autonomy; the CLI itself is cross-platform.

Install the CLI

Install the promoted release globally, then open the loopback console:

npm i -g @ashlr/phantom
phm verse

Check the installed version with phm --version, then browse GitHub releases and select that same version before using desktop artifacts. The console is loopback-only and requires its startup token.

Build from source

Phantom is developed in the open. A source checkout builds and runs the same CLI:

git clone https://github.com/ashlrai/phantom.git
cd phantom
npm ci
npm run build
npm run dev -- status

Agents working on the repository should read AGENTS.md and the agent operations guide first, and can enumerate the command surface with phm docs --agent --json.

Desktop app (macOS)

On an Apple silicon Mac, use the qualified signed-update or maintainer artifact path in the desktop installation guide. Downloading or unpacking an app archive alone does not perform installation. The app is locally signed, not Apple Developer ID notarized; macOS may require Open Anyway on first launch. Desktop installation and fleet activation are separate steps, and resident autonomy stays dormant until a Touch-ID-signed grant starts it.

After install

Follow the quickstart to connect a resource and make a first useful turn, or browse the documentation index for one canonical guide per task.

Machine-readable surfaces: capabilities.json, llms.txt, llms-full.txt and the MCP server manifest.
